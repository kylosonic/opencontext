# Held-out corpus result — 2026-11-24

## Scope

This run exercises a materially larger corpus than the original single-item
quality evidence:

- 32 AMI Meeting Corpus SDM test utterances, concatenated into a 2,102,158-byte
  (SHA-256 `0fca5248af8dd89978a98a3cfda37a96e0d4c0c1cbccaa5f8524d93fcac743c3`)
  far-field conversational recording;
- 16 Screen2Words Android screenshots with semantic text and caption-derived
  visual labels.

Selection, licenses, and citations are pinned in
[`heldout-datasets.json`](heldout-datasets.json). Media is not redistributed by
the repository. Per-item raw context, truth, score, and the aggregate
[`summary.json`](heldout-2026-11-24/summary.json) are published from this run.

## Measured audio

- Provider: local Faster Whisper
- Model: `tiny.en`
- Items: one concatenated recording from 32 clips
- WER: **61.83%**
- CER: **43.81%**
- Transcript segments: 39

The poor result is useful evidence: a tiny general-purpose model is not suitable
for this noisy, multi-speaker far-field composition without better modeling or
audio conditioning. Concatenating isolated clips also removes meeting context
and can create abrupt boundaries, so this is not a full AMI meeting benchmark.

## Visual workflow

All 16 real screenshots passed image decoding, extraction, context generation,
and scoring. The vision and OCR stages used the deterministic fixture provider,
so the reported visual metrics are not model-quality evidence. Their zero/low
values demonstrate why fixture output must be labeled separately: the corpus
genuinely contains text and UI content even though the fixture does not
recognize it.

## Reproduction

```bash
npm run evaluation:heldout:download
HELDOUT_TRANSCRIPTION_PROVIDER=faster_whisper \
HELDOUT_TRANSCRIPTION_MODEL=tiny.en \
HELDOUT_VISION_PROVIDER=fixture \
HELDOUT_VISION_MODEL=fixture \
HELDOUT_OCR_PROVIDER=vision \
HELDOUT_MEASUREMENT_KIND=mixed \
npm run evaluation:heldout:run
```

Run again with an image-capable measured provider to establish real visual
quality. Keep the zero-priced fixture result and measured output separate in
public claims.
