# Roadmap

This roadmap lists work that is not complete. It is not a release promise.

## Now

- Publish the first Python and npm packages through protected environments.

## Next

- Move the worker from a five-minute GitHub Actions schedule to a long-running
  container host.
- Add an audio-backed end-to-end fixture that exercises real speech
  transcription in CI.
- Add CORS for any custom production domain.

## Later

- Expand the measured evaluation beyond one synthetic visual flow and one clean
  speech sample to multiple speakers, noisy audio, dense UI, and degraded
  captures; publish per-item and aggregate results.

## Non-goals

- Fabricated adoption, contributor, or quality metrics.
- Presenting fixture-provider output as real model quality.
- Publishing without a reviewed release tag and manual environment approval.
